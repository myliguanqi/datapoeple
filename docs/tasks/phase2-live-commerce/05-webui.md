# 05 Web UI 设计

## 1. 原则

- **一页一件事**：按功能分页，侧边栏导航；每页最上方是这一页最重要的状态和操作。
- **状态一眼可见**：顶栏常驻 5 个状态徽章：会话（运行/错误）、弹幕（已连接-登录态 / 游客态 / 断开）、TTS（可用/回退/不可用）、LLM（可用/不可用）、RTF。
- **热更新可感知**：设置项旁标"即时生效"或"需重启"；保存后 toast 提示哪些已生效。
- **不做构建**：继续用原生 ES modules（无 npm 构建、无 CDN 依赖，内网/离线可用）。如确需小框架，只能把文件放进 `web/vendor/` 本地引用，并在文档说明。
- 复用现有 `web/player.js`（播放器不改协议）。

## 2. 文件组织

```
web/
  index.html            外壳：顶栏 + 侧边栏 + <main id="page">
  app.js                路由（hash）、全局状态、口令、顶栏徽章轮询、/ws/console 连接
  api.js                fetch 封装（自动带 X-Admin-Token、统一错误 toast）
  ui.js                 组件：card、table、badge、form（由 schema 生成）、modal、toast、confirm、tabs、empty-state
  pages/
    console.js          直播控制台
    danmaku.js          弹幕互动
    products.js         产品与知识库
    media.js            视频素材
    settings.js         直播间设置
    system.js           数字人与系统
    offline.js          离线视频
  scene.html / scene.js 直播场景页（OBS 浏览器源）
  player.js             现有
  style.css             设计令牌（颜色/间距/圆角/字号）+ 组件样式，亮/暗主题
```

### 4.2 弹幕互动

- 顶部：房间号输入 + [连接/断开] + 状态（登录态/游客态、最近消息时间、重连次数）+ [粘贴 cookie]（弹窗，只写）+ 录制开关。
- 标签页：
  - **事件流**：表格（时间、类型、用户[昵称 性别 财富等级 粉丝团等级 熟客/金主徽章]、内容、处理结果）；类型过滤；暂停滚动；点用户名弹出画像卡（长期记忆）。
  - **决策日志**：事件 → 触发器 → 文本来源（模板/LLM/知识库）→ 最终台词 → 合规命中 → 耗时。
  - **触发器**：表格可编辑（启用开关、优先级、冷却、情绪、指令、兜底话术），行内保存即热更新；[恢复默认]。
  - **模拟**：快捷按钮（进场/弹幕/礼物/关注/点赞/产品提问/人数猛涨）+ 自定义表单（昵称、性别、财富等级、礼物、数量）；mock 源开关与速率；回放 JSONL。
  - **观众**：长期记忆搜索（昵称/ID），显示累计进场、送礼、最高财富等级、最近互动。

### 4.3 产品与知识库

- 左：产品列表（拖动排序、启用开关、当前讲解中标记）+ [新建产品]。
- 右：选中产品的标签页：
  - **基本信息**：名称、价格/机制文案、卖点（多行）、讲解时长。
  - **讲解稿**：分段列表（可增删、拖动、编辑）；[用知识库生成]（结果标"待确认"，确认后才参与轮播）；每段显示合规检查结果。
  - **资料**：已关联文档（文件名、类型、切块数、索引状态）、[上传]（拖拽多文件 html/pdf/md）、[重建索引]、[删除]。
  - **视频**：关联的视频（从素材库选）。
  - **测试**：检索测试（显示命中片段与分数）、回答测试（显示最终台词，☐ 让数字人说）。
- 全局文档（不属于任何产品，如店铺售后政策）单独一个"公共资料"条目。

### 4.4 视频素材

网格卡片（封面、时长、分辨率、关联产品），上传、预览、删除；每张卡片 [立即播放 ▾ 全屏/画中画/分屏] [原声/静音]；顶部显示"正在播放"与 [停止]。

### 4.5 直播间设置

- 由 `GET /api/settings` 的 schema 自动生成；左侧分组导航：直播间与弹幕、互动策略、主播人设、语音（TTS）、大模型（LLM）、知识库与讲品、
  直播画面（场景）、合规词库、数字人与推流（大多需重启）、高级。
- 每项：标签 + 控件 + 说明 + 徽章（即时生效 / 需重启）；修改后底部出现"未保存 N 项 [保存] [放弃]"。
- 密钥区：显示 `.env` 中各密钥"已配置/未配置"与 [重新加载 .env]；cookie 显示"已配置（约 N 天前更新）/未配置"与 [粘贴新 cookie]。
- 右上：[导出] [导入] [历史版本]（列表 + 回滚）[恢复默认]（二次确认）。
- 长文本（人设、提示词模板、违禁词表）用多行编辑器，带字数统计。

### 4.6 数字人与系统

现有功能迁入：Lite/Pro 切换、换形象、推送音频、会话列表/新建/关闭、worker 表（GPU、显存、模型、attention、compile）；
新增 TTS/LLM/Embedding 状态卡（可用性、最近耗时、失败次数）、弹幕子进程状态、日志尾部（最近 200 行，可选）。

### 4.7 离线视频

现有功能迁入，布局对齐新组件。

## 5. 交互与视觉规范

- 颜色令牌：`--bg --surface --text --muted --line --accent --ok --warn --bad`，亮暗两套（沿用现有 style.css 的变量名并扩充）。
- 间距 4/8/12/16/24；圆角 6/10；正文 14px，表格 13px，等宽数字 `font-variant-numeric: tabular-nums`。
- 性别显示 ♂/♀/·（不用颜色区分性别）；财富等级用"💎12"短徽章；粉丝团"🎫5"；熟客/金主用文字徽章"熟客""金主"。
- 危险操作（删除、恢复默认、关闭会话、断开弹幕）二次确认；所有异步操作按钮在进行中禁用并显示状态。
- 实时列表限制条数（弹幕流 500、日志 300），超出丢弃最旧；高频事件（点赞、进场）在面板上合并显示（"进场 ×12"）。
- 写接口失败（401）时弹出口令输入；口令存 `localStorage`（try/catch 包裹）。
- 无横向溢出：网格用 `minmax(0, 1fr)`，表格 `table-layout: fixed` + `overflow-wrap: anywhere`，文件输入 `min-width: 0`（现有 style.css 已踩过这个坑）。
